# Steam Sale Predictor

Steam Sale Predictor analyserar historiska Steam-priser och rabatter för att uppskatta möjliga framtida reor.

## Funktioner

- Steam-spelsökning
- Historisk prisdata
- Tidigare rea-historik
- Lägsta historiska pris
- Bästa historiska rabatt
- Prognos för möjlig rabatt
- Uppskattat datum för nästa rea
- Modellens säkerhet
- Prisdiagram
- Svenska kronor
- Felhantering
- Responsiv webbdesign
